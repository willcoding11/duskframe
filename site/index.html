Wrenlight

A free, open-source RAW photo editor with a Lightroom-style workflow. No account, no subscription.

Install with one command (recommended)

The command picks the right build for your machine and avoids the "unidentified developer" and SmartScreen warnings, because files fetched from the terminal are not flagged as downloaded from the internet.

Uninstall: add -s -- --uninstall after bash.

Windows (PowerShell)

No administrator rights needed.
